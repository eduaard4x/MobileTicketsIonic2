# MobileTicketsIonic

## Descrição
Aplicação mobile desenvolvida em Ionic para gerenciamento de filas e senhas em laboratórios médicos.

## Funcionalidades
- Emissão de senhas
- Atendimento prioritário
- Controle de filas
- Painel de chamadas

## Tecnologias
- Ionic
- Angular
- Capacitor
- TypeScript
